# ASMRTube v1.5

YouTube上のASMRを自分用に整理・再生するための静的Webアプリです。

## 目的

- ASMRをタイトル・配信者・タグで整理する
- YouTubeコメント欄のタイムスタンプを貼り付けて再利用する
- 好きなASMRをすぐ再生できるようにする
- 睡眠向け機能をまとめる
- GitHub PagesでURLを開くだけで使えるようにする

## UI方針

LyricTubeと同じシリーズとして使いやすいよう、LyricTubeのレイアウトと必要なCSS設計を流用します。

- 左: 検索、表示切替、プレイリスト、ASMR一覧
- 中央: YouTubeプレイヤー、再生操作、音量、A-Bリピート、作品情報
- 右: LyricTubeの歌詞パネルに相当するタイムスタンプパネル
- 配色、ボタン、パネル、ダイアログ、サイドバーなどはLyricTubeのデザインシステムを基準にする
- 現在選択中作品のサムネイルをヘッダーへ表示
- 設定、バージョン表示、パネルの階層感を追加して製品らしい一貫したUIにする
- 歌詞専用CSSなど、ASMRTubeで不要なものは持ち込まない
- ASMR固有の調整は追加CSS / JSへ分離する

## 崩してはいけない仕様

- YouTube IFrame Playerによる再生
- GitHub Pagesだけで動作する静的構成
- YouTube Data APIキー不要
- localStorage保存
- JSON書き出し / 読み込み
- YouTube動画IDで重複登録を防止
- LyricTubeの保存データへ干渉しない
- ASMRTubeライブラリは `asmrtube.library.v1` を使用する
- 表示設定は `asmrtube.settings.v1` を使用し、ライブラリ保存と分離する

## YouTube情報の自動取得

登録画面へYouTube URLを貼ると、タイトルとチャンネル名を自動取得します。

- 第一候補: YouTube oEmbed
- 取得失敗時のフォールバック: noembed
- APIキーは使用しません
- 取得に失敗した場合は手入力できます
- 保存前にタイトルが空の場合は再取得を試します

## タイムスタンプ取り込み

通常形式:

```text
0:00 開始
3:24 右耳かき
10:51 囁き
```

見出し付き形式:

```text
耳ふー
4:46 右
5:38 左

耳かき
8:20 右
10:15 左
```

表示は見出しを各行へ連結せず、グループとして保持します。

```text
耳ふー
  4:46 右
  5:38 左
```

YouTubeのコメントをコピーした結果、次のように改行が潰れていてもv1.5で解析できます。

```text
2:41 炭酸  耳ふー 4:46 右 5:38 左  5:55 耳塞ぎ
7:13 喋りながらの移動  綿棒 10:48 右 12:30 左  指耳かき 14:02 左 14:07 右
```

この場合、2個以上の空白や改行を論理的な区切りとして扱い、次のように整理します。

```text
2:41 炭酸

耳ふー
  4:46 右
  5:38 左

5:55 耳塞ぎ
7:13 喋りながらの移動

綿棒
 10:48 右
 12:30 左

指耳かき
 14:02 左
 14:07 右
```

再取り込み時は、解析した時刻と同じ時刻にある旧タイムスタンプを置き換えます。旧パーサーで作られた `5:38 左` と `5:38 耳ふー左` のような重複を、元コメントをもう一度取り込むことで修正できます。

保存前プレビューでは `見出し / 時間 / 内容` を修正できます。

## 画面の明るさ

左上の設定ボタンから画面の明るさを変更できます。

- 30〜100%のスライダー
- 100 / 75 / 55 / 35% プリセット
- `asmrtube.settings.v1` へ自動保存
- ライブラリやタイムスタンプデータには影響しない

## 保存場所

ライブラリ:

```text
asmrtube.library.v1
```

表示設定:

```text
asmrtube.settings.v1
```

ブラウザのサイトデータ削除で消えるため、重要なライブラリはJSON書き出しを推奨します。

## 注意点

- 埋め込みを禁止しているYouTube動画は再生できません。
- YouTubeコメント自体は自動取得しません。コメント本文を手動コピーして使います。
- タイトル / チャンネル名の自動取得は外部oEmbed通信に依存するため、通信失敗時は手入力が必要です。
- 見出し判定はコメント形式に合わせたヒューリスティック処理です。誤判定した場合は保存前プレビューで修正できます。
- ブラウザやYouTube側の仕様変更でIFrame PlayerやoEmbedの動作が変わる可能性があります。
